# Metadata

- `dataset_overview.csv`: modality and prespecified role of each public dataset
- `sample_grouping.csv`: public sample identifiers, pseudonymous analysis units, disease/site grouping, and fixed readability exclusions
- `GSE136825_pairing.csv`: title-derived polyp–inferior-turbinate pairing audit and module-score differences
- `marker_panels.csv`: predefined broad-compartment, secretory-state, and ciliary-reference marker panels

No names, medical record numbers, contact details, or non-public clinical identifiers are included.
