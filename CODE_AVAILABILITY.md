# Code availability

The analysis code used for data processing, cell annotation, pseudobulk analysis, module construction, bulk-cohort validation, cross-cohort co-expression analysis, robustness analyses, and figure generation is publicly available at https://github.com/yanjingren97/CRSwNP-serous-defense. The repository contains public sample-level metadata, analysis parameters, selected processed outputs, and Supplementary Data supporting the principal analyses. Raw public datasets are not redistributed and can be obtained from GEO or ProteomeXchange using the accession identifiers reported in the manuscript.
