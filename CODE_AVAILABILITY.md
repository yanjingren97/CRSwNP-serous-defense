# Code availability text for the manuscript

The analysis code used for data processing, cell annotation, pseudobulk analysis, module construction, bulk-cohort validation, cross-cohort co-expression analysis, robustness analyses, and figure generation is publicly available at `https://github.com/<GitHub-username>/CRSwNP-serous-defense`. The locked 40-gene module, public sample-level metadata, analysis parameters, and processed results required to reproduce the principal figures are provided in the repository and Supplementary Data. Raw public datasets are not redistributed and can be obtained from GEO or ProteomeXchange using the accession identifiers reported in the manuscript.

Replace `<GitHub-username>` only after the repository has been created and checked online.
