# Frozen processed results

This directory contains compact processed outputs used to audit the manuscript and regenerate figures. It does not contain raw GEO data or the 119-MB integrated H5AD object.

`locked_40_gene_module.csv` contains the frozen 40-gene module used throughout the public analysis scripts.

Subdirectories follow the analysis stages: single-cell integration, regulatory context, formal models, bulk validation, co-expression reproducibility, robustness, spatial boundary analysis, and proteomic boundary analysis.

The GeoMx and PXD013330 outputs are exploratory. PXD013330 columns are pooled technical measurements, not nine independent patients.
